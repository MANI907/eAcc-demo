## SAP Public Edition

사용자 제공 조건은 `SAP_COM_0002`, 통신 사용자 Basic 인증, API 호스트 `my434089-api.s4hana.cloud.sap`입니다. 이 문자열은 제공받은 그대로이며 DNS·실제 서비스 URL은 아직 검증되지 않았습니다. 구형 ABAP T-code/RFC/JCo를 신규 포탈에서 호출하지 않습니다.

환경 설정에서 다음을 등록해야 합니다. 값은 채팅이나 Git에 저장하지 마세요.

| 이름 | 목적 |
| --- | --- |
| SAP_ALLOWED_HOST | 제공받은 정확한 API 호스트. 현재 제안값은 my434089-api.s4hana.cloud.sap |
| SAP_JOURNAL_WSDL_URL | Communication Arrangement에 표시된 Journal Entry - Post (Synchronous) 서비스의 HTTPS WSDL URL |
| SAP_AUTHORIZATION | 비밀 바인딩. 통신 사용자의 전체 Basic 인증 헤더 (`Basic ` 접두어와 base64 사용자:비밀번호)를 안전한 환경 설정에 입력 |

인증 헤더는 서버에서 HTTPS 요청에 그대로 전달합니다. 프록시가 주입하는 값도 그대로 유지하며 브라우저·로그에는 보내지 않습니다. 인증정보 유출 방지를 위해 리다이렉트를 따르지 않습니다.

현재 실제 검사는 **GET WSDL**과 XML 정의 유효성 검사입니다. 성공해도 전표 전기 권한이나 SAP 업무처리 성공을 의미하지 않습니다. 호스트·HTTPS·WSDL 경로 제한과 TLS 검증을 유지합니다. 네트워크 설정의 저장은 런타임 적용/게시와 다릅니다.

`integrations.journal_xml`은 제한적인 세금없음 일반 비용 전표의 SOAP payload 작성 보조입니다. 검토용이고 실제 전송 경로는 연결하지 않았습니다. SAP 회사코드·계정·공급업체·코스트센터·세금코드·특별 G/L 매핑, 테넌트 WSDL 대조, 중복전기 방지·조회, 오류/타임아웃 대사, SOAP confirmation의 성공 전표번호 검증 후 실제 쓰기 기능을 구현해야 합니다. API 키와 URL이 준비되어도 현재 UI의 모의전기가 자동으로 실제 전기로 바뀌지 않습니다.

2026-11-02 확인: 호스트 접근은 프록시 HTTP 403으로 차단됐고, 인증 바인딩은 미등록입니다. 실제 SAP 연결/전기는 미검증입니다.

## 국내 법인카드 테스트 연동

우선 대상은 **CODEF 공개 샌드박스**입니다. 직접 카드사나 VAN의 법인카드 승인내역 무료 운영 API를 확인한 것은 아닙니다. 카드사·VAN 직접 연동과 달리 수집 중계 API를 사용할 수 있도록 어댑터를 분리했습니다. 바로빌은 대안 후보이며 실제 무료 제공 범위는 미확인입니다.

공식 출처:
- https://github.com/codef-io/easycodefpy : 고정 응답 샌드박스 지원과 샌드박스/데모/운영 구분.
- https://github.com/codef-io/easycodefpy-exam : SDK 사용 예제.
- https://developer.codef.io/ : 카드 상품별 최신 파라미터와 이용조건을 확인할 개발가이드. 현재 프록시 정책 때문에 본문 확인은 미완료입니다.

`easycodefpy==1.0.1` 공식 SDK를 `.runtime/venv`에 설치했습니다. SDK는 샌드박스 호출에도 계정에서 발급받은 RSA 공개키를 요구합니다. `CODEF_PUBLIC_KEY`에 해당 공개키를 환경 설정으로 입력하세요. 고객 카드 로그인·비밀번호·인증서는 수집하지 않습니다. SDK가 자체 제공하는 공개 샌드박스 모드만 사용합니다.

`codef_adapter.py`는 법인카드 승인내역 상품 `/v1/kr/card/b/account/approval-list`에 고정 샌드박스 예시 파라미터로 요청하는 경계 어댑터입니다. 상품 경로·파라미터는 실제 외부 성공 응답 전까지 잠정입니다. 토큰 값이나 원문 응답은 노출하지 않고 결과 코드와 상태만 반환하며, 최대 30초로 제한합니다. 샌드박스 응답은 실제 카드내역으로 DB에 가져오지 않습니다. 수집·정규화·취소/매입대사·중복방지·배치스케줄링은 실제 상품 계약과 응답 스키마 확정 후 구현해야 합니다.

확인 결과: SDK 최초 검사 `CF-00015`는 **로컬 공개키 미설정 오류**였으며 외부 서비스 응답이 아닙니다. 코드에서 이를 `not_configured`로 선제 처리했습니다. 외부 `CF-00000`은 미확인입니다. 무료 실카드 조회나 운영 무료 이용, VAN 계약이 완료됐다고 주장하지 않습니다.

## 저장된 클라우드 설정
